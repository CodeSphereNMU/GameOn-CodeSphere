# Listings Pages

## Overview

Pages for creating, browsing, and managing game listings.

---

## Owner

**Lihlumelo Mgijima** (A100–A700)

---

## Planned Pages

| File | Description | Use Case |
|------|-------------|----------|
| `create-listing.html` | Form to create a new game listing | A100 |
| `browse-listings.html` | Filterable list of open listings | A200 |
| `listing-detail.html` | Single listing view with join/leave/confirm actions | A300, A400, A600, A700 |

---

## Features

- Create listing form (sport, format, date, time, location, capacity)
- Browse with filters (sport, date, status) and pagination
- Listing detail with dynamic actions based on user role (host vs joiner)
- Join request button for non-hosts
- Leave button for current joiners
- Send reminder and confirm session buttons for hosts
