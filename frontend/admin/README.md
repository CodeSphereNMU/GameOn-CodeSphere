## Features

- Table of pending reports (filterable by type: User / Post)
- Report detail view (reporter, reported entity, reason, date)
- Action buttons: Mark as Reviewed, Dismiss
- Status indicators (Pending, Reviewed, Dismissed)
- Admin-only access (redirect non-admins)
