# Architecture Decision Records

This folder contains Architecture Decision Records (ADRs) for GameOn.

An ADR documents a decision that was made and why. Once a decision is accepted, the ADR is not modified (except to mark it as superseded if replaced by a later decision).

## Format

Each ADR follows this structure:
- **Status:** Proposed / Accepted / Superseded
- **Date:** When the decision was made
- **Context:** Why the decision was needed
- **Decision:** What was decided
- **Consequences:** What follows from the decision
