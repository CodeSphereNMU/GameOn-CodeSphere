# Test Evidence

Store test evidence here for assessment submissions:

- Screenshots of passing JUnit test runs
- Screenshots of UI demonstrations (user flows working)
- Console/terminal output showing successful builds
- Database screenshots showing data after test operations

## Naming Convention

Use descriptive names with the feature and date:
```
auth-registration-tests-passing-2026-08-15.png
game-listing-creation-flow-2026-08-20.png
mvn-test-all-passing-2026-09-01.png
```
