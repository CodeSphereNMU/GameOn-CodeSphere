# UI Design References

The `Canva/` folder contains exported screens from the team's Canva design work. These are the visual references for GameOn's frontend.

## Usage

Before implementing or redesigning any frontend page:

1. Identify the relevant Canva screen(s) by filename — most are named after their use case.
2. Use the design's branding, layout, hierarchy, colour direction, and sports-community character as a strong reference.
3. Adapt for accessibility (WCAG AA), responsiveness, and actual business rules.
4. Do not replace the design with a bare, generic interface merely because it is easier.
5. Compare the completed page against the reference before marking frontend work complete.
